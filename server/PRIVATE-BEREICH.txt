SiteGround – passwortgeschuetzter Bereich /private/
===================================================

Lokal (nicht in GitHub):
  daten\              Quelldateien (Excel, PDF, PNG)
  server\private\     FTP-Upload nach public_html/private/

Workflow:
  1. Dateien in daten\price\... oder daten\produkt\... ablegen
  2. scripts\sync-daten-to-private.ps1
  3. FTP: server\private\ -> public_html/private/

Struktur auf dem Server:
  private/
    index.html            Startseite
    .htaccess
    price|produkt/
      graphite|ping-pong-robot/
        index.html        Links zu excel / pdf / png
        excel/            index.php + viewer.php + .htaccess
        pdf/              index.php + .htaccess
        png/              index.php + .htaccess

Passwortschutz: Site Tools -> Security -> Protected URLs -> "private"

WordPress .htaccess (public_html/.htaccess), VOR WordPress-Zeilen:
  RewriteEngine On
  RewriteRule ^private - [L]

(Nicht ^private(/|$) – sonst 404 in Unterordnern.)

Excel im Browser: …/excel/ -> "Im Browser anzeigen" (viewer.php + SheetJS)
